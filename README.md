# 🏁 Pit Wall – GP de São Paulo

Projeto desenvolvido como atividade prática de HTML e CSS, com o objetivo de recriar uma página inspirada no Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

## 📌 Sobre o projeto

O Pit Wall é uma página temática de Fórmula 1 que apresenta informações sobre o GP de São Paulo. O projeto foi desenvolvido utilizando HTML e CSS, colocando em prática os conhecimentos aprendidos durante as aulas.

A proposta foi criar uma página organizada, moderna e visualmente inspirada no universo das corridas.

## 🎯 Objetivo

Praticar os principais recursos de HTML e CSS, trabalhando com organização de conteúdo, estilização, posicionamento de elementos e adaptação da página para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5 – estruturação da página.
- CSS3 – cores, fontes, layouts e estilização.
- Google Fonts – utilização de fonte personalizada.
- Visual Studio Code – editor utilizado no desenvolvimento.

## 🏎️ Funcionalidades e seções desenvolvidas

### 1. Menu superior

Foi criado um menu de navegação com o nome PITWALL e links para acessar as principais partes da página, como pilotos, classificação e ingressos.

### 2. Destaque do GP de São Paulo

A página apresenta uma seção principal com o título GP de São Paulo, uma imagem de destaque e informações sobre o circuito, como número de voltas, distância e curvas.
