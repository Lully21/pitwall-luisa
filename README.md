# 🏁 Pit Wall – GP de São Paulo

Projeto desenvolvido como atividade prática de HTML e CSS, com o objetivo de recriar uma página inspirada no Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

## 📌 Sobre o projeto

O Pit Wall é uma página temática de Fórmula 1 que apresenta informações sobre o GP de São Paulo. O projeto foi desenvolvido utilizando HTML e CSS, colocando em prática os conhecimentos aprendidos durante as aulas.

A proposta foi criar uma página organizada, moderna e visualmente inspirada no universo das corridas.

## 🎯 Objetivo

Praticar os principais recursos de HTML e CSS, trabalhando com organização de conteúdo, estilização, posicionamento de elementos e adaptação da página para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5 – estruturação da página.
- CSS3 – cores, fontes, layouts e estilização.
- Google Fonts – utilização de fonte personalizada.
- Visual Studio Code – editor utilizado no desenvolvimento.

## 🏎️ Funcionalidades e seções desenvolvidas

### 1. Menu superior

Foi criado um menu de navegação com o nome PITWALL e links para acessar as principais partes da página, como pilotos, classificação e ingressos.

### 2. Destaque do GP de São Paulo

A página apresenta uma seção principal com o título GP de São Paulo, uma imagem de destaque e informações sobre o circuito, como número de voltas, distância e curvas.

### 3. Grid de pilotos

Foi desenvolvido um conjunto de cards para apresentar quatro pilotos:

- Charles Leclerc – Ferrari.
- Oscar Piastri – McLaren.
- George Russell – Mercedes.
- Gabriel Bortoleto – Audi.

Cada card possui o número do piloto e uma cor relacionada à sua equipe.

### 4. Classificação

Foi criada uma tabela utilizando as tags `thead` e `tbody`, apresentando a posição, o nome do piloto, a equipe e a pontuação.

### 5. Formulário de ingressos

Foi desenvolvido um formulário com os campos:

- Nome completo.
- E-mail.
- Escolha do setor.
- Quantidade de ingressos.

O formulário foi organizado utilizando CSS Grid.

### 6. Rodapé

No final da página foi colocado um rodapé com a identificação do projeto e o nome da desenvolvedora.

## 🎨 Recursos de CSS utilizados

Durante o desenvolvimento foram utilizados:

- `:root` para definir as cores do projeto.
- Flexbox para organizar o menu e o destaque principal.
- CSS Grid para organizar os cards dos pilotos e o formulário.
- Variáveis CSS para facilitar a utilização das cores.
- `hover` para criar efeitos ao passar o mouse.
- Google Fonts para personalizar a tipografia.
- Imagem de fundo para destacar a seção principal.
- `repeating-linear-gradient` para criar o efeito de zebra da pista.
- `@media` para adaptar a página a celulares e tablets.

## 📱 Responsividade

A página foi preparada para funcionar tanto em computadores quanto em dispositivos móveis.

Foram utilizadas media queries para ajustar o menu, o destaque, os cards, a tabela e o formulário em telas menores.
